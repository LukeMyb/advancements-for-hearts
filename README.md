# Advancements for Hearts

## ゲーム仕様

* **初期HP**
  * ワールド参加時、プレイヤーの最大HPはバニラ標準の「20（ハート10個）」からスタートします。

* **30秒のペナルティタイム (死のカウントダウン)**
  * プレイ時間（IGT）が「30秒」経過するごとに、プレイヤーの最大HPが「1（ハート半分）」減少します。
  * 現在のHPが新しい上限を上回っている場合は、上限に合わせて切り詰められます。
  * 最大HPが0以下になった瞬間、プレイヤーは即死し、以後はリスポーンしても即死し続けるゲームオーバー状態となります。

* **進捗達成による回復 (命の恩恵)**
  * プレイヤーが「進捗（Advancement）」を完全に達成すると、最大HPが「1（ハート半分）」増加し、同時に現在HPも1回復します。
  * 達成時にはプレイヤーに控えめなレベルアップ音が再生されます。
  * ※レシピ解放や各タブの起点となるルート進捗、画面右上に表示されない裏側の内部進捗では回復しません。

* **高精度タイマーとアクションバー表示**
  * 画面下部（体力ゲージのすぐ上）に、現在の最大HPと次の減少までの残り秒数が常に表示されます（例: `[上限: 19] 次の減少まで: 14秒`）。
  * **SpeedRunIGTとの完全同期**: `SpeedRunIGT` 導入環境では、タイマーの進行がIGT（In-Game Time）に完全に依存します。ポーズ中やロード中はペナルティタイマーもストップし、ゲームクリア時（エンダードラゴン討伐時など）には自動的にHP減少タイマーも完全にストップします。また、クライアント側で毎フレーム描画を同期させるため、アクションバーの秒数表示もIGTと1フレームのズレなく完全に同期します。
  * ※本MODは `SpeedRunIGT` を導入してプレイすることを大前提として設計されています（未導入の場合、クリア後もタイマーが止まらなくなります）。

## 動作環境・インストール

* **Minecraft**: 1.16.1
* **Loader**: Fabric Loader 0.19.0 以上
* **必須依存**: Fabric API
* **必須依存**: SpeedRunIGT (正確なIGT同期とクリア時のタイマー停止のため導入必須)

### インストール方法
1. 指定されたバージョンのFabric Loaderを導入したプロファイルを作成します。
2. Minecraftディレクトリの `mods` フォルダに、Fabric API、SpeedRunIGT、および本MODの `advancements-for-hearts-1.0.0.jar` を配置してください。
3. ゲームを起動し、サバイバルを始めてください。
